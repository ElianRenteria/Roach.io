
# Roach.io

Roach.io is a multiplayer game inspired by Agar.io, built using **Pygame** and **Sockets** for real-time player interactions. Players control squares that can move around the screen and compete with others.

## Features

- Real-time multiplayer gameplay using sockets
- Simple graphics with Pygame
- Server-client architecture

## Requirements

- Python 3.x
- Pygame library
- Sockets module

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ElianRenteria/Roach.io.git
   cd Roach.io
   ```

2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Run the server:

   ```bash
   python server.py
   ```

2. Run the client:

   ```bash
   python client.py
   ```

Players can now connect to the server and compete in real-time.
